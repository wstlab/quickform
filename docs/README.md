# QuickForm-docs

本目录为QuickForm的文档。

其实对QuickForm本身来说，几乎不用编写文档，因为太简单。本文档的核心内容在于QuickForm之外，如交互网页的设计原理和技巧，生成式人工智能等提示词技巧，Vibe Coding（氛围编程）入门等。

## 相关信息

阅读地址：[https://quickform.readthedocs.io](https://quickform.readthedocs.io)

系统演示地址：https://quickform.cn
