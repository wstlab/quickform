# 应用技巧：让QuickForm发挥作用

我们认为，QuickForm不过是一个将网页“孤岛”打通，让数据汇集的小工具，具体的能力在于如何与大模型对话，准确表达意图和逻辑。所以，真正的能力不在于QuickForm，而在于AI的使用，在于周边各种工具的协同应用。为帮助大家用好QuickForm，我们整理了一些小技巧。

## 1.网页调试技巧

### 1-1 请使用谷歌浏览器

要点：请使用谷歌浏览器！

问题描述：如果出现数据提交错误，换了电脑就不能使用之类的问题，请记住，要用谷歌浏览器。

理由：要相信大模型的能力。

### 1-2 先网络再本地

要点：先网络调试再本地使用

问题描述：常常有老师表示，跟大模型沟通了很多轮，还是没有成功。一问，往往是使用本地部署的教师版。

理由：本地部署后的调试相对来说要复杂，建议在在线演示的校园版（也称在线版）上测试成功后，再移到本地版本。尤其是第一次使用数据大屏功能，最好在“quickform.cn”

## 2.和大模型对话（提示词）技巧

### 2-1 要不要深度思考

要点：强烈推荐开“深度思考”

问题描述：如果制作复杂功能的网页，如要制作数据大屏，最好做到两点：1.提供数据样式，避免服务器不能去读数据；2.开“深度思考”。还有，不要说“服务器”。

理由：常常有老师说制作数据大屏功能识别，什么读取失败，什么跨域(CORS)限制，最后发现没有打开大模型的深度思考。
https://chat.deepseek.com/share/czo10vn4sz77n5vzwc

### 2-2 和大模型对话要不要新开对话

要点：灵活掌握“新开对话”的机会

问题描述：根据情况，有时要继续对话，有时要新开对话。

理由：对于做好交互网页，分析数据或者做“数据大屏”，最好继续对话。让大模型理解前面的对话内容，知道这些数据代表什么。对于新的任务，千万不要在已有对话中“继续”，会造成“上下文污染”。

## 3.数据看板制作

### 3-1 记得提供数据样例

要点：记得向大模型提供数据样例

问题描述：有些大模型不能直接访问数据地址，要提供数据样例。无论是在线的校园版还是本地的教师版，如果你需要大模型做一个数据大屏（数据看板），除了基本提示词外，最好提供数据样例。

理由：如果大模型能自己去读这个地址，那么仅仅提示词就行。大模型一般都提供了读网页的智能体（技能）。但是有时会读不成功，背后原因很多，也许是被quickform限流了，有时候读不了，比如本地部署的教师版。所以，只要提供数据样例，就一定能成功。所谓的样例，其实就是打开API的地址，将内容复制给大模型。

样例：https://chat.deepseek.com/a/chat/s/0c82ec8e-fd65-4a81-95c2-b659023525a7

### 3-2 数据看板为何忽然间不行了

要点：注意流量，请不要频繁刷新！

问题描述：本来好好的，数据看板忽然间不行了。大概率是流量超标了。

理由：因为很多老师不知道让网页定时刷新，造成QuickForm.cn网站的网络流量很大，我们得支付很高的费用。为了省钱，我们只能限制了流量。不过你只要写个申请理由，就恢复了。

## 4.网页部署方法

### 4-1 网页如何嵌入媒体

要点：提供带互联网访问地址的媒体文件

问题描述：如果用普通的大模型做网页，要将媒体上传到网络上，链接地址。如将视频传到B站上。如果你的网页比较复杂，强烈推荐Trae之类的工具。

理由：没有什么比免费服务更香了，QuickForm的视频也都放在B站上。

### 4-2 多文件网页的部署

要点：使用网站托管服务

问题描述：如果制作的网页不仅仅一个文件，而是多个文件，包括图片、视频之类，甚至拥有多个网页文件，那么你做的就不是“网页”而应该是“网站”。QuickForm自带的功能仅仅支持网页。对于网站，可以借助各种静态网站托管网站来部署你的完网页。其实热铁盒和devfile之类的工具，使用方法都很简单。

## 5.自动化

## 5-1 能不能不打开QuickForm网站就能新建任务等

要点：希望实现自动化CLI接口

问题描述：QuickForm CLI 接口供命令行、豆包工作、WorkBuddy等工具使用。适合高级用户，实现自动化创建与查看数据任务工作。

CLI接口说明：[https://quickform.cn/cli](https://quickform.cn/cli)


## 6.各种疑难问题

### 6-1 浏览器乱码或者页面空白

要点：使用国内资源

问题描述：浏览器打开网页不正常，如图表显示，浏览器中出现乱码等。大部分的原因是，“cdn.jsdelivr.net”这个域名访问不正常。

理由：deepseek、豆包等大模型生成的前端网页中，js往往会使用cdn.jsdelivr.net，看html代码如：
<script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js"></script><script src="https://cdn.jsdelivr.net/npm/chartjs-plugin-datalabels@2.0.0/dist/chartjs-plugin-datalabels.min.js"></script>
