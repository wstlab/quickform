# QuickForm的规划

QuickForm最初仅仅为温州科技高级中学设计，本来并没有什么长远的规划，但是因为喜欢QuickForm的老师太多了，那就不能辜负大家的厚爱，必须把这个项目做好。

我们接下来准备做好这几个工作。

## 维护QuickForm官方网站

让更多教师用上QuickForm，首先需要将QuickForm部署在互联网上。QuickForm的官方网站就是长期在线的校园版，也称“在线版”，支持大规模用户的学习和调试。

目前我们已经申请了独立域名，购买了云服务器。经费来自谢作如和方建文博士的科研经费。实际上也花不了很多钱，最核心的付出是我们的业余精力。

项目介绍地址：[https://quickform.cc](https://quickform.cc)

在线版地址：[https://quickform.cn](https://quickform.cn)

我们计划将QuickForm接入各地的智慧教育平台。如果一切顺利，第一个接入的将会是上海的“三个助手”平台，最终目标是国家智慧教育平台。

## 做好QuickForm的开源工作

QuickForm教师版已经开源，目前已经实现了“内置环境，解压可用”。我们会做好教师版的维护工作，确保能够在不同操作系统稳定运行。

毕竟我们不是企业，没有把握做到让QuickForm网站能同时服务很多人。最稳定可靠的做法是，让更多教师能自行部署和维护QuickForm。我们期望QuickForm如同一颗火种，能唤醒教师们驾驭AI编程（氛围编程）的意识。毕竟，我们也是依赖AI大模型进行编程，自己并没有写过一行代码。

## 做好AI赋能教学的培训工作

AI是工具，但不是传统意义上的普通工具，而是一个能创造新工具的工具，能够自主工作的工具。AI赋能教育教学，不是购买某个企业开发信息系统就完事了，而是要自己能驾驭AI，去完成自己之前做不到的工作，去创造更多的工具，为自己也为他人。

我们期望通过培训，让更多教师通过QuickForm而深度理解AI。只有掌握了AI编程，才能真正理解AI的意义。不要给自己的人生设限，不要划分什么文科理科，有了AI，决定你的成长空间在于你的“心”有多大。

## 实现QuickForm的分布式部署

QuickForm的设计理念是“极简”“交互”。而“极简”的代价是牺牲了数据安全，“交互”导致数据读写频繁。因此QuickForm不宜做长期、敏感的数据采集、保存工作。读写频繁的系统也难以承受大量用户的并发使用，最好的解决方案就是分布式部署。比如，有条件的老师可以部署在自己的笔记本电脑中，有条件的学校可以部署在学校局域网服务器中，有条件的区域教育管理部门，则可以部署一个供全区使用。

我们算过成本，很多学校动辄耗费数万、数十万来购买企业开发的AI教学系统，留点零头就能部署一个QuickForm。但是，前提是有团队能提供QuickForm的商业服务。对于开源项目来说，存在很多可行的商业服务机会，如Linux、安卓等。

## 关于QuickForm的问与答

1.QuickForm开源吗？

QuickForm分为三个版本，在线版、校园版和教师版。目前教师版开源，校园版免费，仅向项目组合作校（单位）开源，在线版面向所有人。

2.QuickForm校园版为什么不开源？

QuickForm校园版在网络上服务，基于安全考虑，我们不能完全开放源码。如果需要，可以和我们签署合作协议，不用付费，只要确保不将源码扩散出去。实际上，大家完全可以基于教师版增加功能。

协议链接：https://mp.weixin.qq.com/s/JIJSxCsL-ImGNuS2UnoAZg

2.QuickForm在线版为什么要“限流”？

为了能支持更多的老师快速体验并学习“QuickForm+AI大模型”，我们提供了在线版。但是我们实在没有能力支持大规模用户同时访问而带来的并发流量，只能限制流量（即短时间内的同时访问频率和接口访问次数），请老师们理解。如果我们得到更多的支持，包括经费和技术两方面，我们肯定会逐步放开限制。

4.QuickForm在线版会收费吗？

我们没有收费的意愿和渠道。虽然有领导期望我们能收费，收很低的费用，但我们并不愿意这样做。如果QuickForm收费了，那一定是说明QuickForm的维护遇到了瓶颈，需要借助外部力量的介入，如需要一定的经费来寻求更加专业的程序员支持。

5.我们需要培训，能支持吗？

对于项目合作的单位，我们将提供相关培训服务，但并非免费而是有偿的。实际上，QuickForm项目组不会直接为项目合作单位来做培训，因为我们有正常的教学工作，难以抽出时间来。但是，QuickForm的微信群里有很多水平高超，研究深入的老师，我们将通过遴选机制，建立一支胜任教师培训的师资队伍，以支持全国各地的培训活动。

6.我可以用QuickForm做收费培训或者课程吗？

我们很期待有更多的老师、大学生、自媒体博主或者商业培训团队，基于QuickForm做收费培训或者收费课程。比如，温州大学的申屠诗怡、黄方濠等七位同学，就在知识星球上做了一个名叫“QF的AI教学后花园”，开通一周内，就有数百教师报名。
