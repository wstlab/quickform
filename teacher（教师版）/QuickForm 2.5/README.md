# QuickForm教师版2.5（纯代码版）

## 软件说明

QuickForm是温州科技高级中学AI科创中心联合温州大学开发的智能表单管理服务，是一个为AI赋能教学而生的开源教学辅助系统。教师借助AI大模型生成交互网页后，可以利用QuickForm提供的API接口回收数据。教师通过对学习数据的智能分析，走向基于数据的精准教学，并逐步提升与生成式AI协同工作的能力。

## 使用方法

本软件为QuickForm教师版，版本号2.5，仅提供纯代码，需要用户自己搭建Python环境。

下载压缩包后，解压，推荐使用龙虾类或者AI编程工具（如QClaw、Workbuddy和Marvis等）配置环境。参考提示词：搭建Python环境，运行"app.py"。

第一次登录，可以用内置的管理账号（用户名：wst，密码：quickform）登录系统，也可以使用在线版的用户名和密码，记得及时修改密码。

**安全提示：**请勿在 QuickForm 中存储姓名、身份证号等敏感数据，详情查看“免责声明”。

## 最新升级说明

- 修复API输出数据格式，和quickform.cn在线版保持一致，数据任务导入即可使用，并实现同步导入数据；
- 支持数据任务的导出功能，包含数据并打包其他文件；
- 增加在线编辑网页功能，可智能替换API地址，自适应不同IP地址；
- API接口支持文件上传和IP记录，内置控制开关，默认关闭；
- 增加多语言（简体中文、繁体中文和英语）支持，走向国际化；
- 重新规划文件结构，便于后续维护和扩展；
- 重新配色，让教师版拥有独特外观。
