# QuickForm：教师版

如果你想在一个全新环境上课时也能稳定使用QuickForm，那么在自己的电脑上安装一个QuickForm教师版，是最好的解决方案。QuickForm教师版使用Python+Flask+Sqlite编写，在任何一台支持Python的电脑都能运行。

## 最新版本

2.5

## 如何本地部署

### 纯代码版

需要自行安装Python环境，安装必要的库。

推荐方案1：使用龙虾类工具，如Qclaw、Marvis来安装环境，要求启动“app.py”即可。

推荐方法2：使用集成Python环境的工具，如mPython、Thonnny。

mPython：https://mpython.cn/

中鸣提供的Thonny+QuickForm：https://ai.zmrobo.com/libs

### 安装版

QuickForm教师版从2.0开始，拥有了正式的安装版本。感谢南宫市红庙中心学校的陈亮老师的付出。

### 一键安装包

下载压缩包后，解压，已经内置了Python环境。

Windows系统：运行QuickForm启动器.bat

MacOS：运行“start.sh”。

Linux：用Linux的都是高手，直接运行“app.py”吧。

## 版本说明

V2.5，支持数据任务导入和导出，支持文件上传，支持多语言，采用单独配色。

V2.0，支持“QF数据互联”（QFLink）功能，可以将在线版的数据任务导入到本地，并且支持本地大模型ollama。

V1.5，功能和界面和校园版保持一致，增加支持的大模型API，优化数据分析功能。

V1.2，修改内置环境，增加项目链接，修改报错提示。

V1.1，增加了“快速启动工具”；增加了提交数据的删除功能；封装为一键启动，解压即可使用。

V1.0，支持多操作系统，Win10以上系统一键启动。
