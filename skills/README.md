# QuickForm技能（Skills）大全

QuickForm很早就提供了API，支持使用智能体自动化操作。2026年7月，QuickForm在线版正式提供CLI。2026年10月，QuickForm教师版也提供了CLI，现在，使用WorkBuddy、豆包工作之类的智能体，能实现不打开QuickForm，就做出一系列的教学工具来。

## quickform-teaching-tool（CLI 版）

### 概述

本 skill 帮助教师快速创建专业的交互式 HTML 教学工具，并自动对接 QuickForm，最终生成数据分析可视化大屏。全程分 8 步完成，同时支持在线版和教师版。

> **版本说明**：本 skill 是 [buBailai/quickform-teaching-tool](https://github.com/buBailai/quickform-teaching-tool) 的 **fork 版本**。

### 安装

方式1：将地址发给WorkBuddy或者豆包工作。

方法2：将压缩包上传到WorkBuddy或者豆包工作。
